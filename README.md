# qstamp-go

A pure Go verifier for Qstamp evidence receipts.

Qstamp binds a record digest to a Merkle root, and the root to a 32 byte commitment that is anchored as a transaction on the Quantova network. This module recomputes that commitment from a receipt and the original record offline, so a verifier confirms the binding without trusting the issuer, and then checks the commitment against the chain through a small reader interface.

The record itself never leaves the holder. Only the 32 byte commitment is public, so a verifier proves that a record existed in one exact form at the anchored time while the content stays private.

## Why Go

The reference Qstamp SDK is JavaScript. This module is an independent Go implementation of the verification path for Go based toolchains, built so supply chain and provenance tools can confirm a Qstamp anchor natively. It depends only on the Go standard library. SHA3 comes from `crypto/sha3`.

## Install

```
go get github.com/quantova-inc/qstamp-go
```

## Use

```go
res, err := qstamp.Recompute(receipt)
if err != nil {
    return err
}
if !res.RootMatches {
    return errors.New("the record does not rebuild the receipt root")
}
// res.Commitment is the 32 byte value that must be anchored on chain.
```

To confirm the anchor against the chain, pass a reader that returns the value placed by the receipt transaction.

```go
res, err := qstamp.Verify(receipt, reader)
```

`reader` satisfies `ChainReader`, which returns the 32 byte value anchored by a transaction. `Verify` recomputes the commitment, checks that the record rebuilds the root, and checks that the anchored value equals the recomputed commitment.

## What it checks

- The record digest and its Merkle path rebuild the root named in the receipt.
- The root, the batch size, the genesis, the contract, the sender and the kind derive the exact 32 byte commitment.
- The commitment equals the value anchored by the receipt transaction, when a `ChainReader` is supplied.

## Conformance

The verification primitives are checked byte for byte against the reference Qstamp SDK over batch sizes from 1 to 2048 and both digest algorithms. The vectors are generated by the reference implementation and committed under `testdata`. Run the suite with `go test ./...`.
